### MAPA 2: CONCEITOS DE CINEMÁTICA
**Título:** "CINEMÁTICA - O Estudo do Movimento"

**Prompt Específico:**
```
Crie um mapa mental educacional sobre CINEMÁTICA.

TEMA CENTRAL: "CINEMÁTICA - Descrevendo o Movimento"

RAMOS PRINCIPAIS (6):

1. REFERENCIAL
   - Ponto de referência para observar movimento
   - Exemplo: pessoa parada vê carro mover
   - Ícone: boneco observando carro

2. POSIÇÃO (S ou x)
   - Localização em relação ao referencial
   - Unidade: metros (m)
   - Ícone: ponto em uma reta numérica

3. DESLOCAMENTO (ΔS)
   - Variação de posição
   - Fórmula: ΔS = S - S₀ (posição final - inicial)
   - É VETOR (tem direção e sentido)
   - Pode ser positivo ou negativo
   - Ícone: seta de A para B

4. DISTÂNCIA PERCORRIDA (d)
   - Caminho total percorrido
   - Sempre POSITIVO
   - d ≥ |ΔS| (sempre maior ou igual ao módulo do deslocamento)
   - Ícone: trajeto curvo

5. VELOCIDADE MÉDIA (Vm)
   - Fórmula destacada: Vm = ΔS / Δt
   - Unidade: m/s ou km/h
   - Conversão: m/s × 3,6 = km/h
   - Ícone: velocímetro

6. VELOCIDADE INSTANTÂNEA
   - Velocidade em um instante específico
   - É o que o velocímetro mostra
   - Ícone: velocímetro com ponteiro

DIFERENÇA IMPORTANTE (box destaque):
"DESLOCAMENTO ≠ DISTÂNCIA"
- Deslocamento: linha reta do início ao fim
- Distância: todo o caminho percorrido

CIENTISTA: Galileu Galilei estudando queda de objetos
```

### MAPA 3: MRU - MOVIMENTO RETILÍNEO UNIFORME
**Título:** "MRU - Movimento Retilíneo Uniforme"

**Prompt Específico:**
```
Crie um mapa mental educacional sobre MRU.

TEMA CENTRAL: "MRU - Velocidade Constante"

DEFINIÇÃO (destaque):
"Movimento em LINHA RETA com VELOCIDADE CONSTANTE"

RAMOS PRINCIPAIS (5):

1. CARACTERÍSTICAS
   - Trajetória retilínea (linha reta)
   - Velocidade constante (não muda)
   - Aceleração = ZERO
   - Ícone: carro em estrada reta

2. EQUAÇÃO HORÁRIA (box dourado grande)
   S = S₀ + v · t
   Onde:
   - S = posição final (m)
   - S₀ = posição inicial (m)
   - v = velocidade (m/s) - CONSTANTE
   - t = tempo (s)

3. GRÁFICOS DO MRU

   Gráfico S × t:
   - Reta inclinada
   - Inclinação = velocidade
   - Se sobe: v > 0 (progressivo)
   - Se desce: v < 0 (retrógrado)

   Gráfico v × t:
   - Reta horizontal
   - Área = deslocamento

4. TIPOS DE MRU
   - PROGRESSIVO: v > 0, S aumenta, a favor do referencial
   - RETRÓGRADO: v < 0, S diminui, contra o referencial
   - Ícones: setas para direita e esquerda

5. EXEMPLOS PRÁTICOS
   - Carro em velocidade de cruzeiro na estrada
   - Luz se propagando
   - Esteira rolante
   - Ícones ilustrativos para cada

FÓRMULA VELOCIDADE (box):
v = ΔS / Δt = (S - S₀) / t

DICA IMPORTANTE (box verde):
"No MRU, espaços IGUAIS em tempos IGUAIS"

ESQUEMA VISUAL:
Linha do tempo com posições marcadas em intervalos iguais
```

### MAPA 4: MRUV - MOVIMENTO UNIFORMEMENTE VARIADO
**Título:** "MRUV - Aceleração Constante"

**Prompt Específico:**
```
Crie um mapa mental educacional sobre MRUV.

TEMA CENTRAL: "MRUV - Velocidade que Muda"

DEFINIÇÃO (destaque):
"Movimento em LINHA RETA com ACELERAÇÃO CONSTANTE"

RAMOS PRINCIPAIS (6):

1. CARACTERÍSTICAS
   - Trajetória retilínea
   - Velocidade VARIA uniformemente
   - Aceleração CONSTANTE (≠ 0)
   - Ícone: carro acelerando

2. ACELERAÇÃO (a)
   Fórmula: a = Δv / Δt = (v - v₀) / t
   - Unidade: m/s²
   - a > 0: velocidade aumenta
   - a < 0: velocidade diminui (freando)
   - Ícone: seta aumentando/diminuindo

3. AS 3 EQUAÇÕES DO MRUV (boxes dourados)

   ① Equação da Velocidade:
   v = v₀ + a · t

   ② Equação Horária (Posição):
   S = S₀ + v₀ · t + (a · t²) / 2

   ③ Equação de Torricelli:
   v² = v₀² + 2 · a · ΔS

4. QUANDO USAR CADA EQUAÇÃO?
   - Equação ①: quando tem tempo
   - Equação ②: quando quer posição
   - Equação ③: quando NÃO tem tempo (TORRICELLI)
   - Box: "Não tem t? Use TORRICELLI!"

5. GRÁFICOS DO MRUV

   Gráfico S × t:
   - PARÁBOLA
   - a > 0: concavidade para cima
   - a < 0: concavidade para baixo

   Gráfico v × t:
   - RETA INCLINADA
   - Inclinação = aceleração
   - Área = deslocamento

   Gráfico a × t:
   - RETA HORIZONTAL
   - Área = variação de velocidade

6. TIPOS DE MOVIMENTO
   - ACELERADO: v e a mesmo sinal (|v| aumenta)
   - RETARDADO: v e a sinais opostos (|v| diminui)
   - Diagrama com setas mostrando combinações

CIENTISTA: Galileu no plano inclinado

DICA (box verde):
"Acelerado ≠ a > 0. Depende do SINAL de v também!"
```

### MAPA 5: QUEDA LIVRE
**Título:** "QUEDA LIVRE - A Gravidade em Ação"

**Prompt Específico:**
```
Crie um mapa mental educacional sobre QUEDA LIVRE.

TEMA CENTRAL: "QUEDA LIVRE - g = 10 m/s²"

DEFINIÇÃO (destaque):
"Movimento vertical sob ação APENAS da GRAVIDADE"
"Despreza-se a resistência do ar"

RAMOS PRINCIPAIS (5):

1. CARACTERÍSTICAS
   - Movimento na VERTICAL
   - Aceleração = g (gravidade)
   - g ≈ 10 m/s² (na Terra)
   - Todos os corpos caem IGUAL (sem ar)
   - Ícone: maçã de Newton caindo

2. EQUAÇÕES (adaptadas do MRUV)

   Substituindo a = g:

   v = v₀ + g · t

   H = H₀ + v₀ · t + (g · t²) / 2

   v² = v₀² + 2 · g · ΔH

   (H = altura)

3. CONVENÇÃO DE SINAIS (importante!)

   Referencial para BAIXO (usual):
   - g = +10 m/s²
   - Descendo: v > 0
   - Subindo: v < 0

   Referencial para CIMA:
   - g = -10 m/s²
   - Subindo: v > 0
   - Descendo: v < 0

   Box: "ESCOLHA e MANTENHA a convenção!"

4. CASOS ESPECIAIS

   QUEDA LIVRE PURA (v₀ = 0):
   - Objeto largado do repouso
   - v = g · t
   - H = (g · t²) / 2

   LANÇAMENTO VERTICAL PARA CIMA:
   - v₀ ≠ 0, para cima
   - Sobe desacelerando, desce acelerando
   - No ponto mais alto: v = 0

   LANÇAMENTO VERTICAL PARA BAIXO:
   - v₀ ≠ 0, para baixo
   - Acelera desde o início

5. TEMPO DE SUBIDA E DESCIDA
   - São IGUAIS (mesmo trajeto)
   - t_subida = v₀ / g
   - Altura máxima: H_max = v₀² / (2g)
   - Ícone: parábola sobe/desce

CIENTISTA: Newton com maçã + Torre de Pisa (Galileu)

EXPERIÊNCIA FAMOSA (box):
"Galileu: bolinha e pena caem juntas no vácuo!"
Desenho: tubo de vácuo com pena e bola

FÓRMULAS RÁPIDAS (box dourado):
- Tempo de queda: t = √(2H/g)
- Velocidade ao chegar: v = √(2gH)
```

### MAPA 6: GRÁFICOS DA CINEMÁTICA (Resumo)
**Título:** "GRÁFICOS - Interpretando o Movimento"

**Prompt Específico:**
```
Crie um mapa mental educacional sobre GRÁFICOS DA CINEMÁTICA.

TEMA CENTRAL: "GRÁFICOS - A Linguagem Visual do Movimento"

ESTRUTURA: Comparação lado a lado MRU vs MRUV

SEÇÃO 1: GRÁFICO POSIÇÃO × TEMPO (S × t)

MRU:
- Formato: RETA
- Inclinação = velocidade
- Mais inclinado = mais rápido
- Horizontal = parado (v=0)

MRUV:
- Formato: PARÁBOLA
- a > 0: "sorriso" (côncava para cima)
- a < 0: "triste" (côncava para baixo)
- Tangente = velocidade instantânea

SEÇÃO 2: GRÁFICO VELOCIDADE × TEMPO (v × t)

MRU:
- Formato: RETA HORIZONTAL
- ÁREA = deslocamento

MRUV:
- Formato: RETA INCLINADA
- Inclinação = aceleração
- ÁREA = deslocamento
- Cruza eixo t = inversão de sentido

SEÇÃO 3: GRÁFICO ACELERAÇÃO × TEMPO (a × t)

MRU:
- a = 0 sempre
- Reta no eixo horizontal

MRUV:
- RETA HORIZONTAL (a ≠ 0)
- ÁREA = variação de velocidade

REGRA DE OURO (box destaque):
"A ÁREA sob o gráfico v×t = DESLOCAMENTO"
"A INCLINAÇÃO do gráfico S×t = VELOCIDADE"
"A INCLINAÇÃO do gráfico v×t = ACELERAÇÃO"

DICAS VISUAIS:
- Setas indicando o que calcular em cada gráfico
- Exemplos numéricos simples
- Código de cores: MRU em azul, MRUV em verde
```
